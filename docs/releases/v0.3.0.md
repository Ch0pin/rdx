RDX v0.3.0 (alpha) introduces a refreshed desktop interface and expands native Java reconstruction.

### Changes

- Refreshed light and dark UI, compact source tabs, app icon, and Android robot for DEX bytecode. Existing syntax themes and preferences remain supported.
- Optional auto-hide for tabs and the top menu, with saved preferences. The menu is visible by default; full class names appear on tab hover.
- Open an independent RDX instance from the app icon or **File → New instance**.
- Labelled MCP status indicator: green when active, gray when inactive, with quick access to server controls.
- Expanded native reconstruction of control flow, allocations, constructors, and supported loop patterns. Unsupported methods still show explicitly labelled DEX disassembly.
- Syntax highlighting remains enabled for very long lines.

Extract the archive fully. On macOS open `RDX.app`; on Windows open `rdx.exe`; on Linux run `./rdx`. Archives include runtime instructions, third-party notices, and the optional source-statistics plugin. Verify downloads against `SHA256SUMS`.

### Requirements and limits

Prebuilt apps require no Rust, Java, Python, or Android SDK. Supported systems are macOS 13+, Windows 10+ x64, and Linux x64 with glibc 2.35+ and a graphical desktop. Linux needs OpenGL and X11 or Wayland libraries; the file picker uses a desktop portal.

macOS builds are ad-hoc signed, not notarized. Windows builds are unsigned and use the static MSVC runtime. First launch may require OS approval. See the [installation guide](https://github.com/Ch0pin/rdx/blob/v0.3.0/docs/install.md).

The native decompiler remains alpha. Reconstruction coverage is not a guarantee of semantic accuracy or compatibility with every APK. Call graphs represent static DEX calls, not runtime traces. See [engine limitations](https://github.com/Ch0pin/rdx/blob/v0.3.0/docs/native-engine.md) and [MCP documentation](https://github.com/Ch0pin/rdx/blob/v0.3.0/docs/mcp.md).
