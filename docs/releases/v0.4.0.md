RDX v0.4.0 (alpha) expands native Java reconstruction, archive support, manifest summaries, and MCP analysis tools.

### Changes

- Open XAPK and APKS archives with validated base/split analysis. Native file-picker reentrancy is guarded to prevent crashes.
- Reconstruct more constructor, allocation, loop, exception, enum, and coroutine patterns. Constructor argument blocks preserve allocation, initialization, branch effects, and exception order; unsupported methods retain explicit DEX fallbacks.
- Read rendered manifest summaries with application metadata, exported components, permissions, and declared deep links. Export Markdown and identify exported components through full-row highlighting.
- Browse annotation metadata, fold Kotlin metadata on nested classes, and read shorter imported type names with collision-aware qualification. Source navigation and search cancellation/recovery receive fixes.
- Use the 19-tool MCP surface with implementation lookup, bounded source search, instance filters, manifest summaries, and ancestor dispatch guidance. Static dispatch suggestions distinguish possible entry points from observed call edges.

### Validation and scope

The measured Android corpus contains 130,576 concrete methods: 124,225 reconstruct to Java (**95.14%**), with 6,351 explicit fallbacks. This measures renderer acceptance on that corpus; it does not establish semantic equivalence for every APK. The final coverage increment gained 204 methods with zero accepted-to-fallback changes against its preceding checkpoint.

Local verification included 340 library tests, 98 focused tests, additional JVM checks of values, effect order and exception identity, formatting, lint, and a release build. Published archives are built and tested by the release workflow on each supported platform.

Extract the archive fully. On macOS open `RDX.app`; on Windows open `rdx.exe`; on Linux run `./rdx`. Archives include runtime instructions, third-party notices, and the optional source-statistics plugin. Verify downloads against `SHA256SUMS`.

### Requirements and limits

Prebuilt apps require no Rust, Java, Python, or Android SDK. Supported systems are macOS 13+, Windows 10+ x64, and Linux x64 with glibc 2.35+ and a graphical desktop. Linux needs OpenGL and X11 or Wayland libraries; the file picker uses a desktop portal.

macOS builds are ad-hoc signed and Windows builds are unsigned. See the [installation guide](https://github.com/Ch0pin/rdx/blob/v0.4.0/docs/install.md), [engine limitations](https://github.com/Ch0pin/rdx/blob/v0.4.0/docs/native-engine.md), and [MCP documentation](https://github.com/Ch0pin/rdx/blob/v0.4.0/docs/mcp.md).
