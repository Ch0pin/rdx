RDX v0.5.0 (alpha) makes APK contents easier to identify and browse, with a dedicated manifest Components view, grouped Assets, and improved Java source presentation.

### Changes

- Inspect manifest components in a table with type, name, exported status, enabled status, launcher status, and individual intent filters. Filter by component type, exported status, or name, expand details, and navigate to the component class or activity-alias target. Exported and enabled values describe manifest configuration; runtime delivery still requires verification.
- Group the Assets tree by folder or file type. Folders appear first, groups display file counts, and hovering reveals the original archive path. Grouping preserves each file's identity and navigation target.
- Identify the loaded app through its icon and package name in the window title. Bitmap, supported vector, and adaptive icons resolve through APK resources and splits, with the RDX icon used when rendering fails.
- Read cleaner reconstructed Java, including string concatenation and default bridges, with the source-readability improvements shipped since v0.4.0.

### Validation and scope

The release workflow checks formatting, lint, tests, and CLI smoke tests for each supported platform before publishing its archives. Local UI checks covered manifest navigation, Assets grouping, and the Life360 adaptive icon. This release makes no new corpus-wide Java coverage claim.

Extract the archive fully. On macOS open `RDX.app`; on Windows open `rdx.exe`; on Linux run `./rdx`. Archives include runtime instructions and third-party notices. Verify downloads against `SHA256SUMS`.

### Requirements and limits

Prebuilt apps require no Rust, Java, Python, or Android SDK. Supported systems are macOS 13+, Windows 10+ x64, and Linux x64 with glibc 2.35+ and a graphical desktop. Linux needs OpenGL and X11 or Wayland libraries; the file picker uses a desktop portal.

macOS builds are ad-hoc signed and Windows builds are unsigned. See the [installation guide](https://github.com/Ch0pin/rdx/blob/v0.5.0/docs/install.md), [engine limitations](https://github.com/Ch0pin/rdx/blob/v0.5.0/docs/native-engine.md), and [MCP documentation](https://github.com/Ch0pin/rdx/blob/v0.5.0/docs/mcp.md).
