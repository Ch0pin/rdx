RDX v0.6.0 (alpha) expands native Java reconstruction and MCP analysis, improves search throughput, and makes incomplete source coverage explicit.

### Changes

- Reconstruct more constructor, loop, switch, and exception-control-flow patterns. Improve source readability, import folding, declaration navigation, and resource hover details. Open source tabs remain available without an arbitrary tab-count limit.
- Search classes in parallel with a larger scheduling window and improved indexing. Keep MCP requests responsive and cancellable during indexing and separate stale UI-selection diagnostics from instance health.
- Inspect source through `class_id` or `class_name`, with per-method `decompiled`, `dex-fallback`, and `omitted` status, reasons, and offsets. Source responses expose pagination and coverage boundaries so callers can identify incomplete output.
- Trace DEX field reads and writes with `find_field_references`, project call graphs into compact filtered call sites, and resolve supported merged-lambda constructor discriminators to their selected switch branch with `get_lambda_branch`. Results preserve method identity and DEX offsets; ambiguous branch mappings remain explicitly unresolved.
- Look up decoded manifest components by class name or intent-filter route, including non-exported components. Inspect exported/enabled state, aliases, permissions, intent filters, and permission protection levels with provenance and unresolved states.

### Validation and scope

The implementation passed the macOS, Linux, and Windows CI matrix before release preparation. Local release-mode validation passed 2,162 tests, with 349 explicitly ignored, plus formatting and all-target Clippy checks. The release workflow checks formatting, lint, tests, and CLI smoke tests on all four release targets before publishing archives.

Source coverage reports reconstruction status; they do not certify semantic equivalence. Manifest results describe declared configuration, and permission resolution uses a pinned Android 16 / API 36 catalog where applicable. Runtime reachability depends on the installed platform and app state.

### Requirements and limits

Prebuilt apps require no Rust, Java, Python, or Android SDK. Supported systems are macOS 13+, Windows 10+ x64, and Linux x64 with glibc 2.35+ and a graphical desktop. Linux needs OpenGL and X11 or Wayland libraries; the file picker uses a desktop portal.

macOS builds are ad-hoc signed and Windows builds are unsigned. See the [installation guide](https://github.com/Ch0pin/rdx/blob/v0.6.0/docs/install.md), [engine limitations](https://github.com/Ch0pin/rdx/blob/v0.6.0/docs/native-engine.md), and [MCP documentation](https://github.com/Ch0pin/rdx/blob/v0.6.0/docs/mcp.md).
