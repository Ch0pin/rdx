RDX v0.8.0 (alpha) improves code search, call-graph navigation, annotation and Retrofit inspection, and Java reconstruction. It also adds region screenshots and resumable source exports.

### Changes

- Improve search scheduling and session-index reuse, add configurable worker and result limits with continuation, and label hits by their enclosing member. Defer out-of-order hit matching and bound pending class markers while retaining memory reservations for uncached source. Late source replies preserve newer graph, analysis, and document navigation.
- Build GUI caller graphs from the shared invoke index, add callers/callees/both selection, arrows, draggable nodes, and exported-state colors. Expose optional inferred dispatch and lambda-creation relationships separately from exact calls, with runtime override checks and constant-argument filtering.
- Inspect annotation usages and recovered Retrofit services from the GUI and MCP. Include parameter annotations and values, type-reference coverage, annotation matching modes, and evidence for recovered annotation roles. Add explicit manifest route matching, near-match diagnostics, exported-state filters, and compact counts.
- Expand reconstruction of inlined constructors, super calls, covariant bridges, checked throws, loop continuations, and condition chains. Fold supported StringBuilder expressions while preserving conversion order and nonempty result identity. Reuse allocation proof context within each method.
- Capture selected UI regions with context-sensitive captions and confirmed PNG destinations. Add resumable source exports, clearer MCP selectors and analysis results, and the Apache-2.0 license with bundled notices.

### Validation and scope

The implementation passed CI on macOS, Linux, and Windows before release preparation. Local validation passed 2,581 enabled tests, strict all-target Clippy, formatting, targeted JVM semantic checks, and the release build. The release workflow repeats formatting, lint, tests, and CLI smoke tests on all four release targets before publishing archives.

A 500-class APK sample preserved search results across cold/warm runs and one/four workers. Four-worker release runs took approximately 0.58–0.66 seconds cold and 7 milliseconds warm. This sample establishes result parity for that workload; it is not a full-APK speed or process-memory guarantee. The debug-profile version of the large-APK sample reached a thread-stack limit; the production release-profile sample passed.

Source coverage describes reconstruction status. Inferred call-graph edges and recovered annotation roles retain their evidence and uncertainty. Runtime-selected Intent destinations and reflection can require additional tracing beyond static references.

### Requirements

Prebuilt apps require no Rust, Java, Python, or Android SDK. Supported systems are macOS 13+, Windows 10+ x64, and Linux x64 with glibc 2.35+ and a graphical desktop. Linux needs OpenGL and X11 or Wayland libraries; the file picker uses a desktop portal.

macOS builds are ad-hoc signed and Windows builds are unsigned. See the [installation guide](https://github.com/Ch0pin/rdx/blob/v0.8.0/docs/install.md), [engine limitations](https://github.com/Ch0pin/rdx/blob/v0.8.0/docs/native-engine.md), and [MCP documentation](https://github.com/Ch0pin/rdx/blob/v0.8.0/docs/mcp.md).
