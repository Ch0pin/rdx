RDX v0.9.0 is a regular release with selectable fallback decompilers, a refreshed desktop interface, shared GUI/MCP source search, and bundled analysis plugins.

### Highlights

- **Selectable fallback decompilers.** macOS and Linux archives bundle the native Androguard and RadGuard helpers. Choose None, Androguard or RadGuard from the toolbar or Preferences. RDX tries the selected helper for methods that failed native reconstruction, labels its output as unverified, and retains the original DEX and diagnostics in an expandable section. Helpers run on demand with bounded execution and per-project caches.
- **Refreshed desktop interface.** Independent Preferences groups appearance, decompilation, scanning and general settings. Toolbar actions, the MCP status badge, active tabs and selected result rows have clearer visual treatment. Search and usage lists share full member labels; long names no longer prevent column resizing. Search jumps into collapsed original DEX no longer lock scrolling.
- **Shared source search.** GUI and MCP searches reuse cached native source, support regex and case options, and expose resumable pagination. MCP can include resource text and decoded XML; coverage diagnostics identify incomplete scans and skipped data.
- **Project analysis and larger APKs.** Bundled plugins include a bounded Logical WebView inventory with separate result windows and MCP access. GUI and headless MCP loading support explicit Standard/Large profiles. Call-graph queries report invalid loaded-method signatures with candidates instead of silently returning a successful empty result.
- **Reconstruction and reliability fixes.** Improve protected-loop reconstruction, checked-call handling and preservation of constants across monitor release. Fix the Linux fallback-worker exit race, strengthen helper packaging/provenance checks, and make plugin tests independent of Cargo output layout.

### Requirements and scope

The core application requires no Rust, Java, Python or Android SDK installation. The optional Logical WebView inventory plugin requires Python 3.9+. Supported systems are macOS 13+, Windows 10+ x64, and Linux x64 with glibc 2.35+ and a graphical desktop. Linux needs OpenGL and X11 or Wayland libraries; the file picker uses a desktop portal. macOS archives are ad-hoc signed; Windows builds are unsigned.

Windows uses the native RDX engine; optional fallback helpers remain unavailable there because worker memory enforcement is not implemented. All alternate reconstruction is explicitly unverified and may contain errors. Native methods that cannot be reconstructed retain labelled DEX output. Large-APK profiles bound parsed-data accounting, not total process memory. Static analysis coverage and runtime reachability remain separate.

The release workflow runs formatting, lint, tests, helper checks and CLI smoke tests on each release target, then verifies all four archive checksums before publishing.
